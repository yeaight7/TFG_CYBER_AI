\chapter{Introduction}

\section{Motivation}
Modern network infrastructures generate vast amounts of traffic, complicating the task of distinguishing legitimate communication from malicious activity. Network Intrusion Detection Systems (NIDS) rely on statistical patterns, flow characteristics, and behavioral modeling to flag potential threats \parencite{ScarfoneMell2007}. As machine learning techniques mature, they offer promising capabilities for managing this complexity on flow-level representations \parencite{Sperotto2010FlowIDS}. However, standard supervised learning typically formulates intrusion detection as a symmetric classification problem, minimizing overall error rather than operational risk \parencite{Axelsson1999BaseRate}. In cybersecurity, the cost of missing a severe attack (a false negative) frequently outweighs the cost of investigating a false alert (a false positive). Reinforcement Learning (RL) provides a natural framework for asymmetric, cost-sensitive decision-making by allowing defenders to optimize for specific reward structures \parencite{SuttonBarto2018RL,Lee2002CostSensitiveIDS}. Exploring how RL algorithms navigate these trade-offs can provide valuable insights into risk-aware automated defense.

\section{Problem Statement}
Applying RL to intrusion detection involves significant methodological challenges. First, high-dimensional network flow data suffers from severe distribution shifts, class imbalance, and artifacts intrinsic to public datasets \parencite{Ring2019DatasetSurvey}. Second, RL models often require extensive data and careful tuning, making it difficult to assess whether they offer empirical advantages over robust, well-understood supervised baselines like Random Forests. Furthermore, many existing studies evaluate models on isolated, randomized partitions of legacy datasets. This approach often fails to expose data leakage---where models inadvertently memorize IP addresses, explicit timestamps, or Flow IDs---or to measure generalization under strict temporal splits \parencite{Arp2020DosDontsMLSecurity,Kaufman2011LeakageDataMining}. The problem is therefore not merely applying an RL algorithm to a network dataset, but rather structuring the problem so that the model's cost-sensitive decisions can be evaluated rigorously, safely, and transparently against established benchmarks and, ultimately, against independent traffic.

\section{Proposed Approach}
This thesis formulates the defensive task as an offline, dataset-as-environment reinforcement learning problem \parencite{Levine2020OfflineRL}. Network traffic is processed into a fixed, 76-feature canonical flow schema, independent of any specific dataset's native format. To manage missing or heterogeneous data---particularly when transitioning from academic datasets to laboratory captures---a 76-value missingness mask is appended, producing a 152-dimensional observation vector for the agent. The mask explicitly encodes presence (\texttt{1}) versus imputation (\texttt{0}), making data gaps transparent to the model.

The decision task is mapped to a binary action space: \texttt{PERMIT} (classify as benign) or \texttt{BLOCK} (classify as attack). A Quantile Regression Deep Q-Network (QRDQN) agent \parencite{Dabney2018QRDQN}, implemented via \texttt{sb3-contrib} \parencite{SB3ContribQRDQNDocs}, is trained within a Gymnasium-compatible environment \parencite{GymnasiumDocs}. This environment explicitly penalizes false negatives more severely than false positives (i.e., a heavier penalty for permitting an attack versus blocking benign traffic) \parencite{Cardenas2006IDSFramework}. The CICIDS2017 dataset \parencite{Sharafaldin2018CICIDS2017,CICIDS2017Web} serves as the primary internal benchmark (Phase 1), strictly processed to exclude leakage-prone fields. Performance is designed to be benchmarked against a Random Forest baseline under progressively stricter validation constraints \parencite{Engelen2021CICIDSIssues}. Finally, the planned second validation tier (Phase 2) introduces offline inference pipelines to process extracted flow features from independently captured laboratory traffic to test domain shift resilience.

\section{Contribution of the Thesis}
This work contributes a reproducible, leakage-aware, and cost-sensitive experimental prototype for evaluating RL-based binary security decisions on flow records. It explicitly defines a canonical feature contract that separates dataset extraction artifacts from the model's observation space. Furthermore, the thesis implements a multi-stage validation ladder---ranging from simple random stratified splits, to day-pattern splits, and leave-one-exact-CSV-out evaluations \parencite{Lanvin2023Errors}. This provides a structured methodology for identifying domain shifts and assessing model robustness. Finally, it is designed to support a same-protocol empirical comparison between QRDQN and supervised baselines, offering evidence on the data-efficiency and trade-offs of the RL approach without overclaiming deployment readiness.

\section{Scope and Limitations}
The scope of this research is strictly confined to offline, tabular flow-level evaluation. The \texttt{PERMIT} and \texttt{BLOCK} actions are experimental binary classifications; the system does not perform live firewall blocking, packet dropping, \texttt{iptables} manipulation, or inline intrusion prevention. Furthermore, the environment does not simulate an active adversary whose subsequent actions change in response to the defender's choices. Consequently, this system is an analytical prototype, not a production-ready NIDS or an autonomous cyber-defense control plane. CICIDS2017 is utilized as an internal benchmark for controlled experimentation, not as definitive proof of generalization to arbitrary networks, with independently captured laboratory traffic prioritized as a subsequent, stricter evaluation tier to assess the limits of the trained model.

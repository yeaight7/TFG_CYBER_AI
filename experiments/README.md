## Status Labels Used Here

- **Historical**: based on legacy experiments already run
- **Maintained**: still useful and aligned with the current repo state
- **Planned**: idea or roadmap item, not yet implemented or not backed by current artifacts

## Notes

- Treat NSL-KDD material as historical benchmarking context.
- Treat `cicids2017_qrdqn_experiments.md` as the maintained experiment-history page for the current Phase 1 baseline.

Validación Externa Ideal: Tráfico propio de laboratorio

Laboratorio privado
↓
Tráfico benigno
DNS / HTTP / SSH / navegación / transferencias
↓
Tráfico malicioso controlado
nmap / fuerza bruta controlada / DoS ligero aislado
↓
Captura
PCAP / flow CSV
↓
Alineación con esquema canónico
↓
Modelo congelado
↓
External validation
Regla clara: El tráfico externo no se usa para entrenar, ajustar reward, elegir hiperparámetros ni tocar preprocessing. Solo se evalúa cuando el modelo ya está congelado.
Caveat: Si el tráfico propio tiene poco volumen o labels débiles, se reporta como validación secundaria/cualitativa, no como único resultado fuerte.

Plan de Evaluación (Jerarquía de rigor)

Plan A

External test con tráfico propio capturado en laboratorio

La mejor opción porque prueba distribution shift/generalization.

Plan B

Split estricto dentro del dataset público

temporal / CSV / escenario / leave-one-out
Buena alternativa si el tráfico propio de lab no es viable.

Plan C

Holdout público grande (ej. 800k flows)

Útil como benchmark interno, pero la evidencia más débil para la generalización final.
